# Nhilat — متجر العسل الطبيعي

تم تحويل قالب متجر الروائع إلى متجر **نحيلات** للعسل الطبيعي، مع الإبقاء على بنية التطبيق وآلية التصفح والسلة وإتمام الطلب والتفاعل كما هي.

## ما تم تغييره
- هوية العلامة والنصوص إلى نحيلات والعسل الطبيعي بالعربية والفرنسية والإنجليزية.
- اللون الرئيسي إلى الزيتي الداكن، مع الحفاظ على لون الخلفية الأصلي `#FAF7F4`.
- الشعار وصور المنتجات والصور الرئيسية وصور الفئات باستخدام الملفات المرفقة.
- المنتجات إلى أربعة أنواع: عسل الخروب، عسل الطلح، عسل الدغموس، وعسل الزنداز.
- العملة ما زالت الدرهم المغربي، والأسعار الحالية تجريبية ويمكن تعديلها في `src/data/products.js`.

## التشغيل
يتطلب Node.js حديثاً:

```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## قبل الإطلاق
- راجع أسماء أنواع العسل، خصوصاً كتابة «الزنداز» وفق الاسم التجاري المعتمد.
- حدّث الأسعار والأوزان وتفاصيل المنتجات حسب بياناتك الفعلية.
- أضف رقم واتساب وروابط التواصل الرسمية للعلامة التجارية.
- اختبر عملية إرسال الطلب والتوصيل على بيئة الاستضافة المستهدفة.


## تشغيل أسهل على Windows
بعد فك الضغط، يمكنك النقر مرتين على `تشغيل-متجر-نحيلات.bat` من المجلد الرئيسي. يحتاج أول تشغيل إلى اتصال بالإنترنت لتثبيت الحزم. اترك النافذة مفتوحة ثم افتح رابط `localhost` الذي يظهر.
